# Citas

Entrega el enlace para agendar, cambiar o consultar una cita presencial o por videollamada.

## Datos de entrada

No exige datos previos. Se abre cuando el cliente pide una cita.

## Mensaje

> Si deseas solicitar o ajustar una cita accede al siguiente enlace:
>
> https://citasprevias.interagua.com.ec/

En el portal puede reservar turno en agencia, cambiar o cancelar una cita, o pedir videollamada.
