# Operador no disponible

Se usa cuando el cliente pide un asesor, o un trámite intenta transferirlo, y no hay operadores libres.

## Datos de entrada

No exige datos previos. Llega cuando la transferencia no encuentra un asesor.

## Mensaje

> En este momento no hay asesores disponibles. En breve un asesor se contactará contigo.

## Salida

Después del aviso vuelve a [0 - Inicio](./0-inicio.md).
